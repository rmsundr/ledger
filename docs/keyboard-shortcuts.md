# Keyboard shortcut map (Phase 1)

| Shortcut | Action |
|----------|--------|
| Enter | Next field / accept menu item |
| Esc | Back / cancel |
| Ctrl+A | Accept / save form |
| Alt+C | Create company (select screen) |
| Alt+D | Delete company (select screen) |
| ↑ / ↓ | Move selection |
| 1–5 | Gateway menu items |
| F2 | Change voucher date |
| F4–F10 | Voucher shortcuts (placeholders until Phase 2) |
| F11 | Company Features |
| F12 | Configure (theme, font scale) |
| Ctrl+Q | Quit application |

The right-hand button bar mirrors the active screen’s shortcuts (Tally-style).
